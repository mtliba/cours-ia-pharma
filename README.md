# Des données aux décisions — three courses on data, AI models and their evaluation in pharmacy

Teaching material by Marouane Tliba (Inserm U1248, Université de Limoges): three courses that follow one
another and share one worked example, therapeutic drug monitoring of tacrolimus after kidney transplantation.
All patients, measurements and tools in the examples are fictitious.

| Axis | Course | Sessions | Slides | Language | Open |
| --- | --- | --- | --- | --- | --- |
| 2 | Programmation et analyse de données | 4 × 2 h (lecture + practical) | 120 | French | [`axe2/site/`](axe2/site/index.html) |
| 3 | IA pour les sciences pharmaceutiques | 10 (4 introductory, 6 advanced) | 226 | French (1–4), English (5–10) | [`axe3/site/`](axe3/site/index.html) |
| 4 | IA responsable et santé numérique | 7 short sessions written for video | 178 | French | [`axe4/site/`](axe4/site/index.html) |

`index.html` at the root is the page that introduces the three courses and links to every session.

## Look at it

The sites load their sessions with `fetch`, so they need a web server (opening the files directly will not work):

```bash
python3 -m http.server 8000
# then open http://localhost:8000/
```

To put it online, enable GitHub Pages on the `main` branch (root folder). The landing page then lives at
`https://<user>.github.io/<repository>/` and every link on it works as is. Before making the repository or the
site public, read "Before you publish" below.

## What is in the repository

```
index.html            landing page (generated by tools/make_index.py)
tools/make_index.py   builds index.html; its figure is drawn from axe2/site/data.json
axe2/                 Axis 2: exported interactive site (4 sessions, data set, 12 figures)
axe3/                 Axis 3: full source (Python), built decks, built site
axe4/                 Axis 4: exported interactive site (7 sessions, slide HTML and word-for-word notes)
CLAUDE.md             instructions for Claude Code: structure, commands, conventions, open points
```

Only Axis 3 has its generator in the repository (`axe3/src`). Axes 2 and 4 were built in earlier sessions:
what is here is their finished site, which contains every slide and every speaker note. Each folder has its
own README with the session list, the links to the slide decks on claude.ai and the points still to check.

## Rebuild Axis 3

```bash
pip install -r requirements.txt
python3 -m playwright install chromium     # only if Google Chrome is not installed
cd axe3 && npm install                     # two font packages, used by the local test pages only
python3 src/build.py                       # ten decks -> out/<name>/project, with layout checks
python3 src/site.py                        # site/index.html + site/sessions/sNN.json
python3 src/sitetest.py                    # loads the ten sessions, widgets and quizzes in a browser
python3 ../tools/make_index.py             # landing page
```

## Before you publish

- The slide decks hosted on claude.ai are private until shared from their own page; the links in the axis
  READMEs open only for their owner.
- The Axis 2 site shows the teacher's notes to anyone who opens it. The Axis 4 site is written for students.
- The click-by-click steps of the decks were checked on a local render, not in the presentation mode of the app.
- Several references are cited from memory and are listed as such in `axe3/README.md` and `axe4/README.md`.
- The two examples taken from the unit's own publications (Woillard et al., 2021) were written from the
  published abstracts and should be read by their authors before the course is shared.
- No licence file has been added yet: choose one before making the repository public.
