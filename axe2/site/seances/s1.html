1 · POURQUOI PROGRAMMER ?

Trois limites du tableur

Des erreurs invisibles

Une formule écrasée par une valeur, un copier-coller décalé d’une ligne : rien ne le signale.

Aucune trace

Quels filtres, quels tris, dans quel ordre ? Le fichier final ne garde pas l’historique des manipulations.

Tout est à refaire

Un nouveau fichier de mesures arrive : il faut répéter à la main chaque étape, avec le même risque d’erreur.

Le tableur reste un bon outil de saisie. La question posée ici est celle de l’analyse.

1 · POURQUOI PROGRAMMER ?

Un script garde la trace de chaque étape

  • Dans un tableur, les manipulations ne sont écrites nulle part.
  • Dans un script, chaque étape est une ligne que l’on peut relire et corriger.
  • Quand un nouveau fichier arrive, on relance le script au lieu de tout refaire à la main.

Variables et types

  • Une variable est un nom donné à une valeur.
  • type() indique le type ; le type détermine les opérations possibles.

greffe_renale = True      # bool : vrai ou faux

print(type(age), type(poids_kg))
print(type(sexe), type(greffe_renale))

<class 'str'> <class 'bool'>

3 · LES BRIQUES DU LANGAGE

Bien nommer ses variables

À éviter

  • x = 70 : soixante-dix quoi ?
  • p2 = 90 : impossible à relire dans un mois.
  • Poids Patient = 70 : les espaces sont interdits dans un nom.

À préférer

  • poids_kg = 70 : la grandeur et l’unité sont dans le nom.
  • creat_umol_l = 90 : on ne confondra pas avec des mg/dL.
  • Minuscules, mots séparés par un tiret bas, sans accent.

Un bon nom de variable répond à deux questions : quelle grandeur, dans quelle unité ?

Écrire l’unité dans le nom de la variable évite une grande partie des erreurs de conversion. On y reviendra avec la clairance de la créatinine.

3 · LES BRIQUES DU LANGAGE

Le piège de la virgule décimale

  • En Python, la virgule sépare des valeurs : elle ne marque pas la décimale.
  • 7,5 est lu comme deux nombres, 7 et 5.
  • Aucun message d’erreur : le calcul continue avec une valeur fausse.
  • On écrit toujours 7.5.

c0 = 7,5          # écriture française…
print(c0)
print(type(c0))

c0 = 7.5          # écriture correcte
print(c0 * 2)

Résultat

(7, 5)
<class 'tuple'>
15.0

print(min(concentrations), max(concentrations))
print(round(sum(concentrations) / len(concentrations), 2))

concentrations.append(9.1)                 # nouvelle mesure

Compter les mesures dans la cible

  • On part d’un compteur à zéro.
  • On l’augmente de 1 chaque fois que la condition est vraie.
  • La proportion est le compteur divisé par le nombre de mesures.
  • f"{x:.0%}" affiche un pourcentage arrondi.

n_cible = 0
for c0 in concentrations:
    if 5 <= c0 <= 10:
        n_cible = n_cible + 1

proportion = n_cible / len(concentrations)
print(n_cible, "mesures sur", len(concentrations))
print(f"{proportion:.0%} dans la cible")

4 · FONCTIONS

Définir une fonction

  • def donne un nom au calcul et à ses entrées.
  • return renvoie le résultat.
  • La phrase entre triples guillemets décrit la fonction.
  • Nommer les arguments à l’appel évite de les inverser.

def dose_journaliere(poids_kg, dose_mg_kg):
    """Dose journalière en mg : poids × dose par kg."""
    return poids_kg * dose_mg_kg

print(dose_journaliere(70, 0.10))
print(dose_journaliere(poids_kg=82.5, dose_mg_kg=0.10))

Résultat

7.0
8.25

4 · FONCTIONS

Exemple : la formule de Cockcroft-Gault

  • La formule estime la clairance de la créatinine, en mL/min. Elle sert à adapter la posologie de nombreux médicaments.
  • La constante k dépend du sexe et de l’unité de la créatininémie : ici, des µmol/L.
  • À vérifier à la main : homme, 60 ans, 70 kg, 90 µmol/L. Résultat : 76,5 mL/min.

La formule sert ici d’exemple de calcul à programmer. Faire remarquer que la constante dépend de l’unité de la créatininémie : ce point resservira à la séance 4.

4 · FONCTIONS

Programmer la formule

  • Les unités figurent dans le nom des arguments.
  • La condition choisit la constante selon le sexe.
  • La fonction renvoie un nombre ; l’arrondi se fait à l’affichage.

def cockcroft_gault(age, poids_kg, creat_umol_l, sexe):
    """Clairance de la créatinine estimée, en mL/min."""
    if sexe == "H":
        k = 1.23
    else:
        k = 1.04
    return (140 - age) * poids_kg * k / creat_umol_l

clairance = cockcroft_gault(60, 70, 90, "H")
print(round(clairance, 1), "mL/min")

Résultat

76.5 mL/min

4 · FONCTIONS

Tester sa fonction sur un cas connu

  • On calcule un cas à la main avant de faire confiance au code.
  • assert reste silencieux si la condition est vraie, et arrête tout sinon.
  • On teste aussi l’autre branche de la condition.

# À la main : (140 - 60) × 70 × 1,23 / 90 = 76,5 mL/min
attendu = 76.5
obtenu = cockcroft_gault(60, 70, 90, "H")
assert abs(obtenu - attendu) < 0.1      # rien ne s'affiche : OK

# Même patient, sexe féminin : k = 1,04
print(round(cockcroft_gault(60, 70, 90, "F"), 1))

Résultat

64.7
