1 · UNE ANALYSE REPRODUCTIBLE

Maîtriser le hasard

  • Un tirage aléatoire change à chaque exécution.
  • Une graine fixée rend le tirage identique d’une exécution à l’autre.
  • On l’écrit dans le notebook, comme tout autre paramètre.

import numpy as np

patients = df["patient_id"].unique()

rng = np.random.default_rng(seed=42)       # graine fixée
print(rng.choice(patients, size=4, replace=False))

rng = np.random.default_rng(seed=42)       # même graine
print(rng.choice(patients, size=4, replace=False))

2 · LES ASSISTANTS D’IA POUR CODER

Leurs erreurs typiques

Fonctions inventées

Un nom plausible, qui n’existe pas dans la bibliothèque. L’erreur s’affiche : elle est facile à voir.

Erreurs silencieuses

Une formule dans la mauvaise unité, une condition inversée. Le code s’exécute et le résultat est faux.

Hypothèses non dites

L’assistant ne connaît ni vos colonnes ni vos unités : il les suppose.

Assurance constante

Le ton est le même, que la réponse soit juste ou fausse.

Une réponse fausse a le même aspect qu’une réponse juste : il faut la tester.

Erreur silencieuse : la mauvaise unité

  • Le code s’exécute sans message d’erreur.
  • La formule attend des mg/dL ; nos données sont en µmol/L.

# Proposé par un assistant : clairance de Cockcroft-Gault
def clairance(age, poids_kg, creatinine, sexe):
    resultat = (140 - age) * poids_kg / (72 * creatinine)
    if sexe == "F":
        resultat = resultat * 0.85
    return resultat

print(round(clairance(60, 70, 90, "H"), 1), "mL/min")

Résultat

0.9 mL/min

Programmation et analyse de données · Séance 4 · Reproductibilité et assistants d’IA

La formule n’est pas fausse en soi : elle est correcte pour des mg/dL. C’est l’hypothèse sur l’unité, non dite, qui produit l’erreur. Sur un tableau de 240 lignes, personne ne la verrait.

Le test révèle l’erreur

2 · LES ASSISTANTS D’IA POUR CODER

La version corrigée et testée

  • L’unité figure dans le nom de l’argument et dans la description.
  • Deux tests couvrent les deux valeurs de la constante.
  • Le notebook garde les tests : ils se rejouent à chaque exécution.

def clairance(age, poids_kg, creat_umol_l, sexe):
    """Cockcroft-Gault, créatininémie en µmol/L."""
    k = 1.23 if sexe == "H" else 1.04
    return (140 - age) * poids_kg * k / creat_umol_l

assert abs(clairance(60, 70, 90, "H") - 76.5) < 1
assert abs(clairance(60, 70, 90, "F") - 64.7) < 1
print("Tests réussis")

Bien formuler sa demande

Demande vague

  • « Calcule la clairance de mes patients. »
  • L’assistant choisit seul la formule, les unités et le nom des colonnes.
  • Aucun moyen de vérifier la réponse.

Demande précise

  • « Écris une fonction Python : Cockcroft-Gault, âge en années, poids en kg, créatininémie en µmol/L, sexe codé H ou F. »
  • « Ajoute un test : homme, 60 ans, 70 kg, 90 µmol/L, résultat attendu 76,5 mL/min. »

La demande précise ne contient aucune donnée de patient : elle décrit le problème, pas le fichier.

Un devoir professionnel

Le secret professionnel du pharmacien s’applique aussi aux fichiers et aux outils numériques.
