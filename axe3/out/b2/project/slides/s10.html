Session 6 of 10 · Attention and transformers

[1 click] Here is the whole block. The input x is normalized, goes through multi-head attention, and the result is added back to x: a residual connection, as in session five. Then a second normalization, a small fully connected network applied to each token separately, and a second residual addition. So the block alternates two operations. Attention moves information between tokens. The MLP transforms each token on its own; it holds about two thirds of the parameters. Stack this block L times and you have a transformer. This is the pre-norm arrangement used in current models; the original 2017 paper normalized after the addition.
