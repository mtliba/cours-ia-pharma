From token to vector

A learned table, plus information about position.

The index of the i-th token in the vocabulary: an integer.

The embedding table: one learned vector of size d per vocabulary entry.

A positional (or time) encoding: tells the model where, or when, token i occurs.

The vector that enters the first block. The superscript counts layers.

After this step every modality is a sequence of vectors.

Session 6 of 10 · Attention and transformers

[1 click] First step: turn each token into a vector. x i is an integer, the index of the token in the vocabulary. E is a table with one row per vocabulary entry; each row is a vector of size d, learned by gradient descent like any other weight. We look up row x i. Then we add p i, a vector that encodes the position of the token in the sequence, or for clinical data, the time of the event. We will see why this is needed in a few slides. The result, h i zero, is what enters the first block. From here on the model no longer knows whether it is reading words or lab values.
