Quelle famille pour quelle question ?

Toxicité des molécules : supervisé. Données : la structure. Cible : toxique ou non.

Prescriptions inhabituelles : non supervisé. Aucune réponse connue ; on cherche ce qui s’écarte des autres.

Mots cachés : auto-supervisé. La réponse est dans le texte lui-même.

Le bon réflexe : chercher d’abord si la bonne réponse est disponible.

[1 clic] La correction. La toxicité : c’est du supervisé, puisque la réponse est connue pour cinq mille molécules. L’entrée est la structure de la molécule, la cible est « toxique » ou « non toxique ». Les prescriptions inhabituelles : c’est du non supervisé, personne n’a étiqueté les prescriptions. Les mots cachés : c’est de l’auto-supervisé. Personne n’a eu besoin d’annoter les textes, la réponse est dans le texte lui-même. C’est ce qui permet d’utiliser d’immenses quantités de données.
