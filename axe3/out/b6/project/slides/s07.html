A token for a clinical event

What was recorded, its value, and when.

The code of event i: which drug, which laboratory test, which diagnosis.

Its value, with its unit: a concentration, a dose. φ is a small network or a binning.

Its time: days since transplant, or age. ψ is a continuous encoding, for example sinusoidal.

The token vector that enters the transformer.

Code, value and real time: three embeddings, summed.

Session 10 of 10 · Multimodal and longitudinal health data: from models to decisions

[1 click] The first design decision is the token. An event has three parts. A code: which test, which drug. A value, with a unit. And a time. The token vector is the sum of three embeddings. The code goes through an ordinary embedding table. The value goes through a function phi: a small network, or a discretization into bins followed by an embedding. The time goes through a continuous encoding psi, for instance the sinusoids of session six evaluated at the real time. Delphi-2M does this with age. This design is not settled: how to embed a numeric value so that the model respects its order and its unit is an active research question.
