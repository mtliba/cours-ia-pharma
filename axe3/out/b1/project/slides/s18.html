[1 click] A routine for failed runs. If the loss is not-a-number: the learning rate first, then gradient clipping, then look for a logarithm of zero or a missing value in the inputs. If the training loss does not move: before anything else, try to overfit a single batch. If the model cannot memorize thirty-two examples, there is a bug, usually in the data pipeline or the labels. If training falls while validation rises: over-fitting, or a shift between your splits. If validation is better than training: often just dropout, but check for leakage. And if results change with the seed, which is the rule with small clinical datasets, report the mean and standard deviation over several seeds.
