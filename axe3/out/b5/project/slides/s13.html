Session 9 of 10 · Foundation models and adaptation

[1 click] The second way to ground a language model is tools. A language model is poor at arithmetic and has no pharmacokinetic model inside it. But it can be given functions to call: a population pharmacokinetic simulator, a database query, a piece of code. The model reads the request, decides which tool to call and with which arguments, receives the result, and writes the answer. A system that chains several such steps is called an agent. The division of labour is the important idea. The language model handles language and orchestration. The number comes from a validated model that you can audit. Every call can be logged, which matters for traceability.
